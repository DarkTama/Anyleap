# AnyLeap Privacy Audit & Data Inventory

> **Scope:** Full codebase audit of data read from Android devices, written to disk on Windows, transmitted over LAN/internet, and system permissions/privileges.
> **Summary finding:** **Zero telemetry, analytics, or crash uploaders exist in AnyLeap.** All phone and multi-PC features run directly over USB or LAN. The only external internet traffic is optional update checks to GitHub (`api.github.com` and `github.com`).

## 5. Log Redaction Summary

The following personal fields were removed or redacted from `kvm-debug.log`:
- **Foreground window titles (`title="..."`):** Removed `GetWindowTextW` lookup and omitted `title="..."` from all `DebugEvent` variants (`Key`, `Engage`, `EngagePerform`, `Return`, `ReceiverEnter`, `RemoteKey`, `RemoteMouseButton`, `Note`) (`src-tauri/src/kvm/debug_log.rs:680-758,767-958`). Process executable names (`proc="notepad.exe"`) are retained without directory paths (`unwrap_or_else(|| format!("pid:{pid}"))`).
- **Transferred file names & relative paths (`rel=...`, `name=...`):** Replaced with deterministic 8-char SHA-256 hashes (`file_hash=...`) across `DRAG_STAGING_FILE_DONE`, `CLIP_STAGING_FILE_DONE`, `STAGING_FAIL`, `DRAG_FILE_SEND_DONE`, `DRAG_FILE_SEND_ERR`, and `DRAG_*`/`CLIP_*` stream lifecycle logs (`src-tauri/src/kvm/commands.rs:975-980,1107-1112,1217-1223,1553-1589`, `src-tauri/src/kvm/files.rs:1271-1330`).
- **Drag result notice text (`notice=...`):** Replaced raw notice text in `DRAG_RESULT_RECV` with `has_notice=<bool>` so failure notices containing filenames are not logged (`src-tauri/src/kvm/commands.rs:1486-1492`).
- **Filesystem paths in error strings, panics, and notes:** Added `redact_paths_in_text` to replace Windows drive paths (`C:\...`), UNC paths (`\\server\...`), and POSIX user/device paths (`/Users/...`, `/home/...`, `/storage/...`, `/sdcard/...`) with `<path:hash>` across `DebugEvent::Note`, `PANIC`, `kvm_debug_note`, and staging/drag error logs (`src-tauri/src/kvm/debug_log.rs:412,595-645,953`, `src-tauri/src/kvm/client.rs:243`, `src-tauri/src/kvm/server.rs:497`, `src-tauri/src/kvm/commands.rs:3881`).
- **Retention & user deletion:** Added a 7-day age cap (`MAX_LOG_AGE`, enforced on startup and log enable) alongside 5 MB × 2 rotation, plus **Delete logs** (`kvm_delete_debug_logs`) in **Settings → Advanced** and **Settings → About → Privacy** (`src-tauri/src/kvm/debug_log.rs:13,495-532`, `src-tauri/src/lib.rs:164-169`).
